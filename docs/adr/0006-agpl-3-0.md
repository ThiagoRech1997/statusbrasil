# 0006. License the project under AGPL-3.0

- **Status:** Accepted
- **Date:** 2026-04-30

## Context

StatusBrasil is a public-interest project: it observes government services that everyone in Brazil depends on, and it aims to publish raw numbers without editorial judgment. The license has to match that stance.

Two pressures shape the choice:

1. We want the source to remain free for anyone to inspect, fork, and run themselves — a permissive (MIT/Apache-2.0) license would allow that, but it would also let a hosted competitor take the codebase, run it as a SaaS, and contribute nothing back.
2. The product is delivered over a network. A GPL-style copyleft would not trigger on network use, because GPL's distribution clause does not consider serving a web app to be "distribution." A commercial fork could keep its modifications private indefinitely.

The license that addresses the network-use loophole specifically is **AGPL-3.0**, which extends GPL's copyleft to include the case of users interacting with the software over a network.

## Decision

**StatusBrasil is licensed under the GNU Affero General Public License v3.0** (`LICENSE` in the repository root). Anyone who runs a modified version of StatusBrasil on a network-accessible service must make the corresponding source code available to the users of that service.

Contributions are accepted under the same license. Contributors sign off on commits per the **Developer Certificate of Origin** workflow described in `CONTRIBUTING.md`; we are not requiring a CLA.

## Consequences

- **Easier:** any improvement to a public deployment of StatusBrasil flows back to the public. Aligns the license with the project's public-interest mission. Compatible with the rest of our chosen stack — Next.js (MIT), Gatus (Apache-2.0), and Plausible (AGPL-3.0) all interoperate cleanly with AGPL.
- **Harder:** AGPL is incompatible with closed-source commercial reuse. Some companies have policies against pulling AGPL code into private products — this will reduce the pool of potential corporate contributors. Embedding StatusBrasil into a proprietary internal tool is not allowed without the source-availability obligation.
- **Committed to:** keeping AGPL-3.0 unless a re-license is negotiated with all contributors. The DCO-based contribution workflow. Any dependency we add must be license-compatible — no GPL-2.0-only or proprietary libraries.
